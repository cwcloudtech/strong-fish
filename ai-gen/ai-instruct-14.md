# AI instruct 14

## Upload events from FFForce

A coach or superuser can upload calendar like [fff-calendar-1.pdf](./assets/fff-calendar-1.pdf) or [fff-calendar-2.pdf](./assets/fff-calendar-2.pdf).

Those calendar has to be automatically parsed to create events:
* use the "all day" option for each event days detected
* use the same color
* for the begin/date and end/date use as prior:
  * written date in the label (it can be written like this `13-05 / 15-05` or `13/05 - 15/05` or `13-15/05`)
  * the color band on the right

Upgrade documentation saying the calendar coming from [this page](https://www.ffforce.fr/fr/force-athletique-ffforce/national-force-athletique/competitions-force-athletique-national/saison-2026-national-fa.html) can be uploaded by coach or superuser.
